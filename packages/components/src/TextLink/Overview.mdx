<div className="sb-unstyled">
  <div className="docs-section">
    <div className="docs-section-title">Text Link or Button</div>
    <div className="docs-subsection-description">
      Use a <strong>Button</strong> for a prominent action: the main call to action, "Weiter",
      "Rechnung herunterladen", also when it navigates (Button with <code>href</code>). Use a{' '}
      <strong>Text Link</strong> for navigation that should not compete with the main action: back
      links ("← Rechnungen"), arrow links ("Erklärung zu Ihrer Rechnung →"), lists of related pages
      and links in running text. If an element does something on the current page without navigating
      (open a dialog, toggle), it is a Button, not a link.
    </div>
  </div>
</div>

<div className="sb-unstyled">

    <div className="docs-section-title">Variants</div>
    <div className="docs-subsection-description">
      Standalone links are not underlined until hover, because the position, the icon and the colour
      already mark them as links. Inline links are always underlined, so they are recognisable
      without relying on colour (WCAG 1.4.1), and take the font of the surrounding paragraph.
    </div>
  </div>
</div>

    <div className="docs-subsection-description">
      Use arrow-left as leading icon for back links and arrow-right as trailing icon for arrow
      links. A leading icon can also describe the destination in link lists. <code>external</code>{' '}

      decorative and hidden with <code>aria-hidden</code>.
