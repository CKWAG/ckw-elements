### Types

The three visual types communicate hierarchy: **Primary** for the main action (gradient background),
**Secondary** for alternative actions (outlined), **Tertiary** for low-emphasis actions (text only).

<Canvas of={ButtonStories.Types} />

### Sizes

Large uses label-l typography (18/22), Medium and Small use label-m (16/20). Small has a reduced
height of 40px.

<Canvas of={ButtonStories.Sizes} />

### Icons

Icons are 24×24 and placed before (leading) or after (trailing) the label. A button may have a
leading OR a trailing icon — never both at the same time. Icon color inherits from the button text
color.

<Canvas of={ButtonStories.Icons} />

### Container

By default the button hugs its content with a minimum width. Set `fullWidth` to stretch it to the
parent container.

<Canvas of={ButtonStories.Container} />
