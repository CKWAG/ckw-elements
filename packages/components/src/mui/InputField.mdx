### Empty

Empty input fields show the placeholder text in a muted color. The Error state shows a red border
and error message below the input. Disabled fields have a muted background and cannot be interacted
with.

<Canvas of={MuiInputFieldStories.Empty} />

### Filled

When the user has entered text, the input value is displayed in the primary text color. All states
behave the same as empty, with the filled text visible.

<Canvas of={MuiInputFieldStories.Filled} />

### Specials

Additional features: a trailing icon inside the input (20 × 20), an "(optional)" hint next to the
label, and an info icon for contextual help.

<Canvas of={MuiInputFieldStories.Specials} />

      The CKW MUI theme can also be used standalone with <code>ThemeProvider</code> to theme any MUI
      component in your app.
    </div>

```tsx
import { ThemeProvider } from '@mui/material/styles';
import { ckwTheme } from '@ckw-elements/components/mui';
import MuiTextField from '@mui/material/TextField';

function App() {
  return (
    <ThemeProvider theme={ckwTheme}>
      <MuiTextField variant="outlined" placeholder="CKW Styled" />
    </ThemeProvider>
  );
}
```
