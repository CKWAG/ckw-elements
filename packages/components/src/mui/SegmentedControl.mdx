### Types

**Default** segments size to their content. **Fill** stretches all segments equally to fill the
container width — useful for full-width controls in forms or toolbars.

<Canvas of={MuiSegmentedControlStories.Types} />

### Icons

Segments support an optional icon alongside the label. Pass a 24×24 SVG as the `icon` prop on each
segment object.

```tsx
import { ThemeProvider } from '@mui/material/styles';
import { ckwTheme } from '@ckw-elements/components/mui';
import ToggleButtonGroup from '@mui/material/ToggleButtonGroup';
import ToggleButton from '@mui/material/ToggleButton';

function App() {
  return (
    <ThemeProvider theme={ckwTheme}>
      <ToggleButtonGroup value="a" exclusive>
        <ToggleButton value="a">Option A</ToggleButton>
        <ToggleButton value="b">Option B</ToggleButton>
      </ToggleButtonGroup>
    </ThemeProvider>
  );
}
```
