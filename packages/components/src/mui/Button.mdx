### Variants

The three visual variants communicate hierarchy: **Primary** for the main action (gradient
background), **Secondary** for alternative actions (outlined), **Tertiary** for low-emphasis actions
(text only).

<Canvas of={MuiButtonStories.Variants} />

### Sizes

Large and Medium share 48px height with different typography; Small is 40px. All use pill-shaped
border radius via `--border-radius-full`.

<Canvas of={MuiButtonStories.Sizes} />

### Full Width

Buttons can stretch to fill their container. Useful for mobile layouts or stacked button groups.

```tsx
import { ThemeProvider } from '@mui/material/styles';
import { ckwTheme } from '@ckw-elements/components/mui';
import MuiButton from '@mui/material/Button';

function App() {
  return (
    <ThemeProvider theme={ckwTheme}>
      <MuiButton variant="contained">CKW Styled</MuiButton>
      <MuiButton variant="outlined">Secondary</MuiButton>
      <MuiButton variant="text">Tertiary</MuiButton>
    </ThemeProvider>
  );
}
```
